# Навигатор поддержки и ИИ-решений НСО (прототип)

Статический сайт (без сборки и сервера), работает на GitHub Pages.

- `data/solutions.json` — 63 решения из «Электронного каталога решений с применением ИИ» (Проектный офис Минцифры НСО, август 2026), размечены по задачам вручную.
- `data/measures.json` — меры поддержки с источниками и датой проверки (8.10.2026).
- Ответы пользователей хранятся только в браузере (localStorage). В рабочей версии нужен серверный модуль на инфраструктуре министерства (152-ФЗ).

Локальный запуск: `python3 -m http.server`, затем http://localhost:8000
Публикация: Settings → Pages → Deploy from branch → main / root.
